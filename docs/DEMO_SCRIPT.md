# Demo script

With `APP_ENV=local`, `DEMO_MODE=true`, and `SEED_DEMO_ACCOUNTS=true`, use `investigator / investigate123`, create a DEMO case for `0xReported001`, run INVESTIGATE, inspect the graph and primary path, select an intermediary and WHY, save a transaction as evidence, run REPLAY, ask “Where did the money go?”, then generate the report. Explain that all records are synthetic, processing completion does not close the case, and action-request statuses do not verify external action.
